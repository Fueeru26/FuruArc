# Security Policy

## Supported versions

Only the latest release receives fixes.

## Reporting a vulnerability

Please do not open a public issue for security problems. Use GitHub's private vulnerability reporting ("Security" tab > "Report a vulnerability") for this repository, and include the affected version, steps to reproduce and, if possible, a minimal sample file.

FuruArc works on files you choose and does not upload them anywhere. Network access is used only for the features you start yourself or enable: online translation (the text you send is transmitted to the provider you select), cover search, and the update check against the GitHub Releases API. FuruArc never downloads or installs an update by itself.

Signing keys and passwords are never stored in this repository; if you find a secret committed here, please report it privately.
